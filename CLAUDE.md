This repo builds Noah's CV for **2027 graduate roles in finance** (wealth management, banking, FX/trading operations, accountancy schemes). It is a public repo, so never commit his phone number or home address: they live in the gitignored `contact.json`.

## How to build
- `npm install` then `npm run build` → `output/Noah_Sargeant_CV_Finance.docx`
- All CV wording lives in `build_cv.js`. Text in `[square brackets]` renders highlighted yellow as a placeholder still to fill.
- Keep it to two A4 pages, single column, standard headings (ATS-friendly). UK conventions: no date of birth, no photo, no full address.
